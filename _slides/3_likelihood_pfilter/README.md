Built from the former `3_likelihood` and `4_pfilter_in_pomp`.

## What this lecture covers

The likelihood → attempt 1 (direct simulation) fails → the **particle
filter** evaluates `L(θ)` → the answer is random (`logmeanexp`) → the
effective-sample-size diagnostic. It ends by handing off to `B_mle_mif2`:
"we can score any fixed θ; next, find the best one."

The likelihood + particle-filter **theory/formulas** are in the appendix at
the end of the deck.

## Conventions (please keep these)

**The model is defined once.** `scripts/model_measSIR.R` is the single
source of truth and is byte-identical to `B_mle_mif2/scripts/model_measSIR.R`.
Parameters: `Beta=15, Gamma=0.5, Rho=0.5, k=10, Eta=0.06, N=38000`.

> Historical note: the old decks disagreed — `3_likelihood`/`4_pfilter_in_pomp`
> used `Gamma=0.5`, `mif`/`5_IF_theory` used `Gamma=2`. Both are `0.5` here.
> If you copy a cache from an old folder, **check its `Gamma` first.**

**Two visual registers.** Hand-drawn-style sketches (`figures/*_graph.pdf`,
generated by their `.py` scripts) carry **the idea**; generated `fig-*.png`
carry **the evidence** — always computed from the real Consett data.

**Colour has fixed meaning** (Okabe–Ito, colourblind-safe): `#E69F00` amber =
the data; `#0072B2` blue = the method that works; `#D55E00` vermillion = what
fails; `#009E73` green = truth/reference; grey = latent/context.

**Figures never hardcode axis limits or label positions** — derive from the
data. **Never write a number you did not compute** — each figure script
recomputes its own annotations and prints them.
